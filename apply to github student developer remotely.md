To change your GPS location in Google Chrome using custom latitude and longitude coordinates, use the built-in Chrome DevTools. [1, 2] 
## Steps to Override Geolocation

   1. Open Developer Tools:
   * Right-click anywhere on the webpage and select Inspect (or press Ctrl + Shift + I on Windows/Linux or Cmd + Option + I on Mac). [3, 4] 
   2. Access the Sensors Tab:
   * Look at the top or bottom of the DevTools panel and click the three-dot menu (Customize and control DevTools).
      * Hover over or select More tools, then click Sensors. (If you don't see "Sensors," click the three-dot menu next to the DevTools close/minimize buttons or press Esc to open the console drawer, click the + icon, and select Sensors.) [3, 5, 6] 
   3. Enter Custom Coordinates:
   * Find the Location drop-down menu (it usually says No override by default).
      * Change it to Other...
      * Type in your desired Latitude and Longitude values. (You can also click Manage or Add location to save these coordinates as a preset for future use.) [1, 2, 5, 6, 7] 
   4. Refresh the Page:
   * Keep the DevTools window open and refresh the webpage (F5 or Cmd + R). Any site requesting your geolocation API will now read the new latitude and longitude. [3, 5, 8]
